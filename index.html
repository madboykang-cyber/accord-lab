PROCESS

시안을 먼저 보고 결정합니다

어떤 작업이든 순서는 같습니다. 결과물을 눈으로 확인한 뒤에 진행 여부를 정하는 안심 후불제라 손해 볼 일이 없습니다.

  1. 1. 문제 듣기

    카톡 · 전화로 지금 불편한 점과 목표를 듣습니다. 자료가 없어도 됩니다. 어떤 조합(프로그램 · 영상 · 웹)이 맞는지 여기서 정합니다.

  2. 2. 설계 · 1차 시안

    화면 흐름과 데이터 구조를 설계하고, 영업일 3일 안에 실제 동작하는 링크로 1차 시안을 보여드립니다.

  3. 3. 제작 · 검수

    시안을 보고 결정한 뒤 본 제작에 들어갑니다. 중간 결과를 링크로 공유하고 피드백을 바로 반영합니다.

  4. 4. 오픈 · 운영

    도메인 연결 · 검색 등록 · 사용법 안내까지 하고 오픈합니다. 오픈 후 1개월 수정 무제한, 이후 운영 요청은 카톡으로.

시안 보고 결정하는 후불제

서버비 · 관리비 없이 운영

FAQ

자주 묻는 질문

비용은 어떻게 정해지나요?+

작업 범위를 듣고 견적을 드립니다. 프로그램은 화면 수와 연동 범위, 영상은 길이와 편수, 웹은 섹션 수와 예약 · 결제 같은 기능 유무로 정해집니다. 견적은 서면으로 드리고, 시안을 본 뒤에 결정하시면 됩니다.

프로그램은 어디서 돌아가나요?+

웹 기반으로 만들어 PC · 태블릿 · 휴대폰 브라우저에서 바로 씁니다. 설치가 필요 없고, 직원별 계정과 권한을 나눌 수 있습니다. 데이터는 대표님 명의 저장소에 보관됩니다.

기존에 쓰던 엑셀 · 프로그램 데이터를 옮길 수 있나요?+

네. 엑셀 · CSV · 기존 시스템 내보내기 파일을 받아 새 프로그램에 맞게 정리해 넣어드립니다.

영상 촬영도 해주시나요?+

촬영 소스를 주시면 편집 · 자막 · 모션 · 음악까지 완성합니다. 촬영 소스가 없으면 사이트 화면 · 제품 사진 · 저작권 무료 영상으로 구성해 드립니다. 현장 촬영은 지역에 따라 별도 상담합니다.

자료가 하나도 없어도 되나요?+

됩니다. 카톡 인터뷰로 소개글을 같이 쓰고, 사진이 없으면 저작권 걱정 없는 이미지로 먼저 구성한 뒤 나중에 교체해 드립니다.

오픈 후 수정과 운영은요?+

오픈 후 1개월은 수정 무제한이고 카톡으로 요청하시면 3일 안에 반영합니다. 이후에도 문구 · 이미지 교체는 가이드대로 직접 하실 수 있고, 기능 추가는 그때 범위를 보고 안내합니다.

결과물은 누구 소유인가요?+

소스 코드 · 도메인 · 데이터 모두 대표님 명의로 등록합니다. 나중에 다른 개발자에게 맡겨도 그대로 이어받을 수 있습니다.
